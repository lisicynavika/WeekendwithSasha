# Программы на наш культурный отдых

Персональный путеводитель для пяти друзей по Санкт-Петербургу на **14–15 ноября 2026**.

## Запуск

1. Распакуйте весь архив, сохранив структуру папок.
2. Откройте папку `cultural-weekend` в Visual Studio Code.
3. Нажмите правой кнопкой по `index.html` → **Open with Live Server**.

Node.js, сборка, установка пакетов и ключи API не нужны. Можно открыть `index.html` двойным щелчком; через Live Server поведение сохранения настроек предсказуемее. Интернет требуется только для перехода на сайты организаторов и карты. Все фотографии, иллюстрации и шрифты лежат локально.

## Что работает

- Два дня: три программы в субботу, две в воскресенье; 48 остановок из исходного задания.
- Крупный закреплённый переключатель дней, переходы к отдельным вариантам.
- Светлая кремовая и тёмная сливовая темы с сохранением выбора.
- Один выбранный маршрут на каждый день; замена выбора и сохранение в этом браузере.
- Раскрытие всего расписания и отдельных остановок. Остановки главных активностей и вечернего финала раскрыты изначально.
- Реальные фотографии Петербурга в галерее: увеличение, предыдущая/следующая, стрелки клавиатуры, Escape, закрытие по фону, смахивания на телефоне. Иллюстрации тоже увеличиваются.
- Кнопки маршрутов и отдельных адресов в Яндекс Картах, ссылки на афиши и организаторов.
- Клавиатурная навигация по вкладкам стрелками, Home и End, видимый фокус, возвращение фокуса после галереи, системное уменьшение анимаций.
- Адаптивная сетка: широкие экраны, планшеты, одна колонка на телефоне.

Сохранение выполняется через localStorage. Если браузер запретил его, интерфейс работает в текущем сеансе и сообщает, что выбор сохранить не удалось. Перенос выбора между устройствами не предусмотрен.

## Как редактировать

- `js/data.js` — пять программ: время, описания, адреса, ссылки и точки маршрута. Не переименовывайте `id`, если хотите сохранить прежние пользовательские выборы.
- `js/main.js` — интерфейс, подписи галереи, список проверенных источников, интерактивность.
- `css/style.css` — палитры обеих тем, размеры и адаптивные правила. Цвета задаются переменными в начале файла.
- `assets/images/` — пять JPG реальных городских мест и пять SVG тематических иллюстраций активностей.
- `assets/fonts/` — локальные вариативные Unbounded и Golos Text с кириллицей и лицензиями SIL OFL. Их не нужно скачивать отдельно.
- `Техническое задание.txt` — предоставленный исходный документ.

## Фотографии и права

Фотографии получены с Wikimedia Commons под открытыми лицензиями. Автор, исходная страница и лицензия каждой фотографии указаны в `assets/images/credits.json`, в `PHOTO_CREDITS` в `data.js` и под увеличенным изображением в галерее. В макете фотографии кадрируются CSS; исходные скачанные JPG не ретушировались. При дальнейшем использовании соблюдайте соответствующую лицензию, включая атрибуцию и ShareAlike там, где он требуется.

Фотографии показывают городские места в разные сезоны: они не обещают погоду или внешний вид города в ноябре. Это не фотографии конкретных мастер-классов или игровых залов. Для активностей созданы и подписаны собственные тематические SVG-иллюстрации. Визуальные референсы использованы для направления оформления, не включены в распространяемый проект.

## Проверка перед передачей

Проверены синтаксис JS, наличие локальных файлов и изображений, структура пяти программ и 48 остановок, сценарии переключения/выбора/сохранения/галереи в изолированной проверке интерфейсной логики. Браузерный просмотр и визуальная проверка на всех разрешениях не выполнены: инструмент предпросмотра не установил соединение. Поэтому полный визуальный аудит и отсутствие ошибок консоли в реальном браузере не заявляются. После запуска через Live Server рекомендуется просмотреть обе темы на своём телефоне.
